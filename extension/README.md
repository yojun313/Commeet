# Commeet → POVIS 자동입력 (데모)

Commeet에 로그인해 면담 기록을 불러오고, 그 내용을 POVIS 입력 화면에 채우는
확장입니다. 아직 **타당성 검증용 데모**입니다 - POVIS 쪽 필드 매핑이 임시이기
때문입니다(아래 "아직 모르는 것" 참고).

## 설치

1. Chrome에서 `chrome://extensions` 열기
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 `extension/` 폴더 선택
4. 툴바의 확장 아이콘 클릭

권한은 POVIS와 Commeet 두 도메인(+ 로컬 개발용 localhost:8000)뿐입니다.

## 쓰는 법

1. **로그인** — Commeet 계정으로 로그인합니다. 기본 서버는
   `https://commeet.postech.ac.kr`이고, ⚙ 버튼으로 로컬 서버(`http://localhost:8000`)
   등으로 바꿀 수 있습니다.
2. **내 일정** — 내가 만든 일정만 나옵니다(면담 기록은 주최자만 작성하므로).
   고른 뒤 **면담 기록 불러오기**.
3. **면담 기록** — 그 일정의 기록 목록. 날짜·시간·장소로 구분되며, 작성 중인
   초안은 `[작성 중]`으로 표시됩니다.
4. **학생** — 참석한 학생만 나옵니다. 고르면 학업지도/생활지도/진로지도/기타사항
   네 갈래 내용이 그대로 보입니다.
5. **POVIS에 채우기** — POVIS 탭을 띄운 상태에서 누릅니다.
   **되돌리기**로 원복, **필드 스캔**으로 현재 화면의 필드 경로를 뽑습니다.

**저장은 하지 않습니다.** 화면 값만 바꾸며, 서버 반영은 POVIS의 저장 버튼을
직접 누를 때만 일어납니다. 되돌리기를 하거나 새로고침하면 원래대로 돌아갑니다.

비밀번호는 저장하지 않습니다. 로그인 요청에 한 번 실려 갈 뿐이고, 남는 것은
브라우저가 관리하는 Commeet 세션 쿠키뿐입니다.

## 기록에서 값을 꺼내는 규칙

틀리기 쉬운 곳이라 코드(`popup.js`의 `notesFor`)와 함께 적어 둡니다.

- `notesMode`가 `"individual"`이면 학생별 노트(`perStudentNotes`), 아니면
  공통 노트(`sharedNotes`)를 씁니다.
- `perStudentNotes`의 키는 **학번이 아니라 참석자 `key`**입니다. Commeet 화면
  코드가 이름으로도 폴백하므로(`record-form.js:710`) 여기서도 `key` → `name`
  순으로 찾습니다. 동명이인이 있으면 어긋날 수 있습니다.
- `present === false`(불참자)는 목록에서 제외합니다.
- `undecryptable`(복호화 실패) 기록은 배지로 표시합니다 - 내용이 비어 보이는
  것을 "빈 기록"으로 오해하지 않도록.
- 빈 항목은 채우지 않습니다. POVIS에 이미 있는 값을 빈 문자열로 덮지
  않기 위해서입니다.

## 왜 이렇게 만들었나 (POVIS 쪽)

POVIS는 SAPUI5(1.120.21) 앱입니다. 두 가지가 구현을 결정했습니다.

**1. 모델에 써야 한다.** `field.value = ...` 후 `input`/`change` 이벤트를 흉내
내는 흔한 자동입력 방식은 여기서 **조용히 실패합니다**. 화면에는 새 값이
보이지만 UI5 모델은 옛 값 그대로라, 그 상태로 저장하면 옛 값이 전송됩니다.
실측 결과:

| 방법 | 화면 | UI5 모델 |
|---|---|---|
| DOM 직접 쓰기 + 이벤트 | 새 값 | **옛 값** |
| `model.setProperty(path, v)` | 새 값 | 새 값 |

그래서 채운 뒤 반드시 되읽어 일치를 확인하고 `OK`/`불일치`로 보고합니다.

**2. 필드는 바인딩 경로로 찾아야 한다.** UI5가 붙이는 DOM id(`__area57-inner`)는
로드마다 바뀝니다. `/GS_GOAL/ZGOAL` 같은 바인딩 경로는 백엔드 필드명이라
안정적입니다.

콘텐츠 스크립트의 격리된 world에서는 `window.sap`이 보이지 않으므로
`chrome.scripting.executeScript({ world: "MAIN" })`으로 페이지 컨텍스트에
들어갑니다.

## 아직 모르는 것 / 주의

- **지도면담입력 화면을 아직 못 봤습니다** (교수 계정 필요). 그래서 POVIS 필드
  매핑(`popup.js`의 `DEMO_FIELD_MAP`)이 임시로 미래설계 화면의 30·40·50·60대
  칸을 가리킵니다. 교수 화면에서 **필드 스캔**을 돌려 나온 경로로 그 상수를
  바꾸면 그대로 동작합니다.
- **인증이 아직 검증되지 않았습니다.** Commeet 세션 쿠키가 `SameSite=Lax`라,
  확장에서 보낸 요청에 쿠키가 실리는지는 크롬 동작에 달려 있습니다. 로그인은
  성공했는데 이후 호출이 401로 돌아온다면 이 문제입니다. 그 경우 대안은
  (a) Commeet 탭의 content script에서 same-origin으로 호출한 뒤 확장에 전달,
  (b) 확장 전용 읽기 토큰. `docs/povis-extension-handoff.md` 참고.
