POVIS 일괄 입력

POVIS 학사 → 지도학생면담 → 지도면담입력 탭을 열어 두세요. 이 회의의 참석 학생 전원에 대해 학번 선택 → 지도면담 입력 → 네 항목 채우기 → 저장을 반복합니다.

    저장 폴더

    Chrome 확장은 다운로드 폴더 아래에만 저장할 수 있어, 폴더는 다운로드 폴더 기준 하위 경로입니다 (예: POVIS/2026-2).

    선택한 학생만

    POVIS 입력 화면(면담결과입력)이 열려 있을 때, 위에서 고른 학생의 내용만 채웁니다. 저장은 직접 누르세요.
