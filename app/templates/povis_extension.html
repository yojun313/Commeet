설치

  1. 설치 파일을 받아 압축을 풉니다

    위 설치 파일 다운로드로 받은 zip을 더블클릭해 압축을 풀면 commeet-povis-{{ version or "x.y.z" }} 폴더가 생깁니다. Chrome은 이 폴더를 계속 참조하므로, 다운로드 폴더에 두지 말고 문서 폴더처럼 지우지 않을 곳으로 옮겨 두세요. 폴더를 지우면 확장 프로그램도 사라집니다.

  2. Chrome에서 확장 프로그램 관리 화면을 엽니다

    주소창에 아래 주소를 입력합니다. (보안상 페이지 안의 링크로는 열리지 않아, 직접 입력해야 합니다.)

    chrome://extensions

    또는 메뉴(⋮) → 확장 프로그램 → 확장 프로그램 관리.

  3. 오른쪽 위 개발자 모드를 켭니다

    스위치를 켜면 왼쪽 위에 압축해제된 확장 프로그램을 로드합니다 버튼이 나타납니다.

  4. 압축해제된 확장 프로그램을 로드합니다 → 1번에서 풀어 둔 폴더를 선택합니다

    manifest.json이 바로 들어 있는 폴더를 고르세요 (zip 파일이 아니라 폴더입니다). 목록에 Commeet → POVIS 자동입력이 나타나면 끝입니다.

  5. 툴바에 고정합니다 (선택)

    주소창 오른쪽 퍼즐 조각(🧩) 아이콘 → Commeet → POVIS 자동입력 옆의 핀을 누르면 툴바에 아이콘이 보입니다.

Chrome을 다시 켤 때 "개발자 모드 확장 프로그램 사용 중지" 안내가 뜰 수 있습니다. 웹 스토어 밖에서 설치한 확장에 늘 나오는 안내이며, 취소(그대로 두기)를 누르면 됩니다.

사용법

  1. POVIS에서 입력 화면을 열어 둡니다

    POVIS 로그인 → 학사 → 지도학생면담 → 지도면담입력. 지도학생 목록이 보이는 화면이면 됩니다. 이 탭을 열어 둔 채 다음으로 갑니다.

  2. 확장 아이콘을 눌러 {{ APP_NAME }}에 로그인합니다

    가입한 이메일 주소 전체(예: hong@{{ ALLOWED_EMAIL_DOMAIN }})와 비밀번호. 비밀번호는 저장되지 않습니다.

  3. 회의를 고르고 면담 기록 불러오기

    내가 만든 일정 중 면담 기록이 있는 것이 위에 옵니다. 기록을 고르면 참석 학생 목록과 각자의 상태(입력 예정 / 학번 없음 / 내용 없음)가 보입니다.

  4. N명 자동 입력을 누릅니다

    POVIS 탭에서 학생마다 자동으로 진행됩니다. 팝업을 닫아도 계속되고, 다시 열면 진행 상황과 학생별 결과(저장됨 / 건너뜀 / 실패)가 보입니다. 중단은 지금 학생을 끝낸 뒤 멈춥니다. 작업 중에는 POVIS 탭을 조작하지 마세요.

옵션

  • 같은 날짜 면담이 있어도 입력 — 기본은 POVIS에 같은 날짜 면담이 이미 있으면 그 학생을 건너뜁니다(두 번 입력 방지).
  • 입력 화면 스크린샷 저장 — 저장 직전 화면을 회의이름_면담일_학생이름.png로 Chrome 다운로드 폴더에 남깁니다. 하위 폴더(예: POVIS/2026-2)를 지정할 수 있습니다.

문제가 생기면

  • "POVIS 탭을 찾지 못했습니다" — 같은 Chrome 창(프로필)에 POVIS 지도면담입력 탭이 열려 있어야 합니다.
  • "세션이 만료되었습니다" — 팝업에서 다시 로그인하세요.
  • 학생이 "목록에 없음" — POVIS 지도학생 목록(검색 조건: 지도학생, 학적상태)에 그 학번이 없는 경우입니다. POVIS에서 검색 조건을 넓힌 뒤 다시 실행하세요.
  • "실패 — 면담결과를 입력하세요" — POVIS 화면 구조가 바뀌었을 가능성이 큽니다. {{ SUPPORT_EMAIL }}로 알려 주세요.
